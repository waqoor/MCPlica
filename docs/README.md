# MCPlica authoritative documentation

1. `architecture.md` — architecture and boundaries.
2. `design_document.md` — technical design and contracts.

6. `open_source_and_sponsorship_model.md` — governance, CLA, ownership, and sustainability.

Latest explicit decisions override earlier conflicting decisions. The starter code is only a foundation; implement remaining phases against these documents.
